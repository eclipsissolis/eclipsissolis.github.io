# Мои смены

Сайт, который достаёт из скриншота расписания смены одного человека: загружаешь картинку, пишешь имя — получаешь список.
Всё работает в браузере (распознавание — [tesseract.js](https://github.com/naptha/tesseract.js)), скриншот никуда не отправляется.

## Как это устроено

- `src/core.js` — разбор таблицы: поиск сетки, чтение подписей и дат, чтение имён в ячейках (цвет фона вычитается, остаётся чистый текст), нечёткий поиск имени.
- `src/ocr.js` — обёртка над tesseract.js (несколько воркеров).
- `app.js`, `index.html` — страница.
- `tessdata/` — языковые модели Tesseract (`rus` для имён, `eng` для цифр времени).
- `vendor/tesseract/` — сам движок tesseract.js целиком (главный скрипт, воркер, wasm-ядро). По умолчанию
  tesseract.js подгружает это с `cdn.jsdelivr.net`, но этот CDN бывает недоступен или медленно грузится
  из некоторых сетей, из-за чего страница зависает на «Загружаю распознавание…» без единой ошибки. Поэтому
  весь движок лежит прямо в репозитории — сайт ничего стороннего не скачивает.

## Запуск локально

Открывать `index.html` двойным кликом нельзя (браузер блокирует модули и воркеры для `file://`). Нужен любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Создай репозиторий и загрузи в него всё содержимое папки (вместе с `tessdata/` и `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

**Не загружай в репозиторий реальные скриншоты расписания** — на них имена других людей, а репозиторий публичный.

## Ограничения

- Рассчитано на расписание такого шаблона: даты в первой строке, слева секции / места / время, ячейки с именами.
- Скриншот лучше брать в исходном размере; при ширине меньше ~1000 px мелкий текст читается хуже.
- Светлая таблица с тонкими линиями сетки. Другие шаблоны могут потребовать правки `detectGrid` в `src/core.js`.
- Первый запуск скачивает около 8 МБ языковых данных, дальше они кешируются браузером.
- Год на скриншоте не указан, берётся текущий.
